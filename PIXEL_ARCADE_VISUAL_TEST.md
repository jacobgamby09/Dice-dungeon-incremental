# Pixel Arcade Visual Test — Adopted

Status: afsluttet og godkendt den 2026-07-30.

Den isolerede test på `codex/pixel-arcade-visual-test` beviste, at spillet blev
mere læsbart og mere umiddelbart med:

- ren sort canvas;
- hårde hvide pixelrammer;
- få mættede gameplayfarver;
- mindre dekorativ dungeon-støj;
- de eksisterende fysiske 3D-terninger som hero-objekter.

Retningen er nu valgt som spillets officielle visuelle design. Den bindende
produktionsreference er flyttet til `DESIGN.md`, og den videre konsolidering
foregår på `codex/arcade-foundation-v1`.

Testbranchens gameplay, saves, balance, enemy-sprites og dice-logik blev ikke
ændret. Den forbliver frosset som sammenligningspunkt for den oprindelige
vertical slice.
